# 术语表

| 术语 | 含义 |
| --- | --- |
| Peer scope | `(remote_id, connection_id, session_epoch)`，拥有可靠状态 |
| 可靠包序号 | 仅由可靠 DATA 消耗的序号 |
| 安全序号 | 每次签名尝试消耗的独立 64 位序号 |
| Session | 显式可信的方向性安全关联 |
| 工作区 | 调用者或后端预留的实例及有界资源池存储 |
| Profile | 编译能力和结构体布局 |
| PHY | 同步帧消费与有界流读取 |
| 背压 | 存储或应用繁忙时，在接纳前拒绝 |
| 墓碑 | 关闭后保留的安全槽，用于防止 nonce 域复用 |
