# 性能与资源

以目标 ABI 的实际链接消费者测量资源。静态库大小和主机 `sizeof` 不能作为 MCU 资源预算。

## 资源证据

可复现的 Cortex-M0 命令和测量范围见 `tools/boot_footprint/README.md`。报告记录工具链选项、来源摘要、已链接 ELF、map 和栈使用文件，包含静态 workspace 并单列预留栈；不测量中断、板卡 Flash 驱动或栈高水位。

## 吞吐量

`test/benchmark` 程序报告主机观察值。联合调整 MTU、轮询周期、RX 字节预算及独立保留包容量；只扩大窗口而不增加保留存储不能增加实际容量。真实链路速度、丢包、驱动缓冲和 Flash 延迟须在板卡上测量。
