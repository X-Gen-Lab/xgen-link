# 数据链路

Datalink 隔离 PHY 字节 I/O 与协议包，不持有可靠性、peer 身份或可信会话状态。

## 接收组帧

PHY 收到的字节可能截断在帧头或帧内，也可能包含多个帧。增量解析器保留有界的半帧状态，识别 magic/帧头布局，并向上提交完整帧。半帧仅在配置的接收缓冲区与帧超时限制内保留。错误长度、帧头 CRC 和最终帧 CRC 在本地 transport 处理前拒绝。

规范 wire 解码器验证完整帧布局。CRC 用于检测传输错误；本地 network 投递执行认证策略与验签。解码得到 AUTH 标志不代表已经验签。

## 同步发送契约

PHY 发送回调返回前必须停止读取借用缓冲区。成功表示同步提交完成，失败返回协议调用方。Datalink 不为 DMA 完成事件保留指针，也不提供异步所有权 token。

DMA 驱动必须先复制到驱动自有存储再返回，或等待发送完成。协议 scratch 随后可以立即释放，用于 ACK/控制帧或下一帧。回调执行不得重入实例。

## 限制与调度

编译期帧长上限和配置的链路 MTU 都约束完整序列化帧，包括扩展、标签和 CRC。`xgl_step` 接收显式时间与接收工作预算。`xgl_next_timeout` 汇总链路轮询与 transport 期限；轮询链路时检查半帧过期。存在且为零的延迟表示工作已到期。驱动通过就绪通知或轮询发现新接收字节。
