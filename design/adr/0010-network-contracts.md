# ADR 0010：静态路由、链路装配与已验证帧边界

- 状态：已实施
- 日期：2026-10-01
- 范围：network、实例链路装配、同步零拷贝结果统计

## 背景

路由配置同时包含目的出口与 PHY 轮询提示。原先重复目标按最后一项覆盖，所有不同 PHY 却仍注册和保留接收存储；metric 不参与选路。正常接收端点还支持 raw 回退，使 LTO 把较大解码局部对象带入已验证 view 的路径。零拷贝成功计入 transport，失败没有对应计数。

## 决策

1. 保持公开配置布局和 wire v3。静态实例配置拒绝目标零、本机目标及重复目标，允许显式广播出口。私有 route add 保留更新语义；整表加载先检查有效性，再替换已有内容。
2. 工作区规划和初始化共用 PHY 去重规则，一个唯一 PHY 对应一个 parser/cache。轮询频率只作为初始化提示，同 PHY 采用最短周期；运行路由更新不改变链路生命周期。
3. 保留兼容字段，不增加 sidecar、另一套路由表或运行时服务注册。metric 明确保留且不参与选择；动态路由、仅接收链路配置和多路径不属于当前能力。
4. 内部帧 RX 消息只携带必需的已验证 view。独立 raw 接收入口继续检查实例上限和完整帧；正常路径不重复解码或 CRC。转发只从 view 读取帧地址与长度。
5. 转发保留完整有界副本和同步提交所有权，释放所有失败路径的 scratch，透传下层错误；端点 transport 负责可靠重传，network 不增加转发队列。
6. 零拷贝明确区分基础请求拒绝与进入统一 network 发送。后者成功计入 transport TX，失败计入 transport TX error；查询无发送副作用，不通过错误码或其他层统计反推阶段。
7. 删除无生产用途的通用 network 错误包装，保留历史回归名称并改为调用真实发送错误路径。共享少量 RX 拒绝计数，不构造通用错误框架。

## 后果与验证

以前被接受的无效或重复静态路由现在提前返回错误；不能依赖重复目标为仅接收 PHY 注册资源。公开结构和符号保持兼容，私有 frame RX 调用方迁移到 view。接收原始帧的能力仍独立存在。

扩展临时数组容量不缩减。只有在所有读字节均先写入的条件下取消整段清零；Flash、栈和工作区由最终 Cortex-M0 ELF 验收，不以对象文件或主机数据替代。Boot 的线性路由与其他 profile 的索引策略保持现有构建身份。

GoogleTest 覆盖静态拒绝、整表加载原子拒绝、部分初始化失败释放、共享 PHY、错误返回与统计、可靠多跳与反向 ACK、认证和未知 TLV、广播以及 MTU/BUSY 恢复。默认随机流之外保留种子 15 的地址前置条件回放。具体命令和资源结果记录在[network 验证记录](../validation/network-optimization.md)。
