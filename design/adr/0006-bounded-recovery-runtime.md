# ADR 0006：有界恢复、调度与可查询资源

状态：已采用。日期：2026-10-01。

## 问题

职责归并之后，重复 SACK 仍可能重复触发成功快重传；第一次可靠 RX 接纳失败留下没有有效历史的 peer。parser 超时依赖 PHY 轮询，应用回调错误不能稳定返回调用者。旧原地发送入口只有默认 scope，固定池的预留量也难以从资源预算解释。Boot 缺少与其能力一致的单元测试，中间能力组合只能选择完整 Embedded。

## 可靠状态与错误

- 每条待确认记录至多执行一次成功的 SACK 快重传；已经重传过的记录由 RTO 处理后续重试。BUSY 不计为成功、不增加重试次数，也不消耗后续重试机会。
- 第一次 RX 接纳失败，且 peer 没有已接纳历史、保留数据或失败状态时，立即归还新建 peer 和窗口；已建立的序列历史不能用这个规则清除。
- RTT 更新使用足够宽的中间结果，再执行既有上下界限制。显式包超时优先，其次为有效 RTT 估计，最后为配置默认值。
- 发送和重传统计在成功提交点更新；某个成功后又发生 BUSY，不撤销前面的成功计数。

## 调度与调用契约

实例记录最近一次有效 `xgl_step()` 的 parser 超时策略。零表示禁用，修改超时不重启部分帧的原始计时。维护不依赖链路是否到轮询时间，也不依赖本次 RX 字节预算是否非零；`xgl_next_timeout()` 合并这个期限。

一次 step 保留首个接收错误，继续处理已经读到的字节及后续 transport 维护。损坏流仍按 parser 同步和诊断规则处理；应用 BUSY 是调用者可处理的背压，不应令示例或产品停止调度。维护并不保证固定 CPU 时间：RX 字节上限仍按链路计算，产品应验证完整循环的实时性。

同实例串行化、回调不可重入、同步 PHY 返回前消费或复制字节的契约不变。此次不增加线程、全局时钟或运行时服务注册。

## 兼容扩展和唯一所有者

旧公开请求和结构 ABI 保留。独立的 scoped zero-copy 请求包含 connection/epoch；旧入口继续使用零 scope。布局查询只返回精确 payload 偏移和所需容量，不分配、不调用 provider/PHY、不消耗 nonce。实际发送仍重新验证有效性；可靠原地发送不在支持范围。

`xgl_memory_report()` 复用初始化使用的唯一布局算法。类别包含对齐，合计等于精确工作区大小；失败不写输出。固定池预留量与共享接纳预算分别表达，不通过降低接纳预算宣称实际预留等比例下降。

security 是认证策略和 provider 的唯一所有者。network 借用它；link 的 parser 拥有唯一 cache 指针。删除没有消费者的私有字段，并合并 transport TX 私有声明；不增加公共组件副本。

## 配置和资源

Boot/Embedded/Full 的构建身份 301/302/303 保持。新增 Embedded Lite 304，保留分片、乱序、路由索引和统计，关闭认证与转发。安装包导出能力并验证必需 components，产品只采用明确支持的组合。

Boot 逻辑 TX metadata 上限为 32 字节，覆盖 SESSION、ACK 和 DATA_TYPE 组合；纯 wire 编解码仍保留完整扩展长度规则。该约束减少同步发送的栈缓冲，不能据此声称支持任意自定义 Boot TX metadata。

Boot 单测按实际能力选择；Full 保留全部历史回归。每种 profile 独立生成配置、编译和安装。固定工具链生成 MTU 128/64 两个真实 ELF，回归限额与 8 KiB Flash 的设计目标分别记录，栈预留也不当作板上测量。
